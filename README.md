# 🍹 Mojito Cocktails — High-Performance GSAP Landing Page

A responsive, ultra-smooth landing page built with **React**, **Tailwind CSS**, **Vite**, and **GSAP**. Designed to demonstrate intentional animation engineering, optimal performance, and scroll-driven interactivity.

🌐 **Live Demo:** [https://gsap-mojito-cocktails-six.vercel.app/](https://gsap-mojito-cocktails-six.vercel.app/)

---

## 🔥 Star Feature & Viral Reception

The standout highlight of this project is a **scroll-synced video animation** featuring an ice cube dropping seamlessly into a cocktail glass as the user scrolls.

During early development, a teaser video showcasing this single feature went viral on LinkedIn, trending for **4 consecutive weeks**, generating **thousands of weekly impressions**, over **150+ likes**, and extensive community engagement. 

> *Original concept inspired by community tutorials, re-engineered and optimized for web performance.*

---

## ✨ Key Features & Animation Architecture

This project was built to showcase **GSAP mastery**—focusing not just on movement, but on *intent, timing, and user psychology*.

* **Scroll-Synced Ice Cube Video:** Frame-accurate scroll scrubbing powered by GSAP ScrollTrigger.
* **Seamless Cocktail Showcase Slider:** Interactive menu with Next/Previous navigation and direct selection. Items slide into place naturally with zero layout shift, flicker, or re-render blinking.
* **Thoughtful Motion Design:** Every element moves with purpose, guiding the user's focus without overwhelming the visual hierarchy.
* **Performance-First Approach:** Leveraged GSAP over alternative animation tools to ensure 60 FPS performance, lightweight bundle footprint, and buttery-smooth scrolling across all devices.

## 🚀 Getting Started

To run this project locally, follow these steps:

### Prerequisites
Make sure you have Node.js (v16 or higher) installed on your system.

### Installation

1. **Clone the repository:**
   ```bash
   git clone [https://github.com/YOUR_USERNAME/YOUR_REPO_NAME.git](https://github.com/YOUR_USERNAME/YOUR_REPO_NAME.git)
   cd YOUR_REPO_NAME

```

2. **Install dependencies:**
```bash
npm install

```


3. **Start the development server:**
```bash
npm run dev

```


4. Open your browser and navigate to `http://localhost:5173`.
